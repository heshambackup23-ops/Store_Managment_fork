# جرد الوظائف وتكافؤ Cloud Edition

المصدر `90baabb4b38ae292ea7ef55806145518774991bb`. استند الجرد إلى `routes/` و`app/Models` و`app/Services` و`app/Http` و`database/migrations` و`resources/views` و`config/access.php` وواجهات Retrofit. يوضح [سجل الحالة](PROJECT_STATUS.md) حدود ما ثبت بالاختبار.

| الوحدة | السلوك وعلاقات المصدر | قواعد التحقق والصلاحيات والمخاطر عند النقل |
|---|---|---|
| Dashboard | `HomeController` يجمع الكتالوج والعملاء والفواتير والأقساط والتنبيهات | صلاحية لوحة التحكم. احتساب فواتير اليوم والأسبوع حسب تاريخ العمل، وتحييد المرتجعات وتحديد الفرق بين النقد والمبيعات |
| Categories | عرض/بحث/إضافة/تعديل/حذف وتصنيف المنتج، `CategoryPolicy` | اسم فريد وفصل صلاحيات CRUD، وتقييد الحذف عند وجود منتج مرتبط |
| Products | CRUD، باركود، صورة، تصفية، طباعة ملصق، `ProductsPolicy` و`PictureStorageService` | تحقق من السعر والكمية وفردية الباركود وملكية الصورة. وحدات صغرى ورصيد لا يغيره نموذج المنتج مباشرة |
| Inventory | الحقل `products.stock` تؤثر فيه الفاتورة والتالف والاسترجاع | سجل حركة مستقل، منع رصيد سالب وقابلية مراجعة الافتتاح والتسويات |
| POS | بحث وباركود وسلة وإيصال. `CashierCheckoutRequest` و`InvoiceCreationService` | الخادم يقرأ سعر المنتج ويتحقق من الكمية قبل تأكيد عملية ذرية. البيع الآجل يحتاج عميلًا قابلًا للتتبع |
| Invoices | إنشاء/عرض/بحث/تعديل/سداد/استرجاع/طباعة. `invoices.product_id` و`items`، ومزامنة القسط | ضبط تكرار رقم الفاتورة، حفظ الأسعار وقت البيع، ربط الدفعات والحركات. لا يُعاد احتساب الفاتورة القديمة بسعر اليوم |
| Customers | CRUD والدفتر المرتبط بالفواتير والأقساط والمحافظ عبر `CustomerLedgerService` | منع كشف الهاتف والعنوان، ومعالجة أسماء العملاء التاريخية النصية قبل الربط بمعرّف |
| Installments | إنشاء وتعديل وعرض وسداد وتغيير الحالة وحذف، مع فاتورة وعميل ومنتج محتملين | `InstallmentWorkflowService` و`InvoiceInstallmentSync`. الاستحقاق، منع تجاوز المتبقي، والتوفيق بين سجل القسط والفاتورة |
| Personal debts | CRUD وسداد شخصي وسجل دفعات مستقل. `PersonalDebtService` | قيد المبلغ والمتبقي والصلاحيات، واستخدام مفتاح آمن عند إعادة المحاولة |
| Suppliers / purchases | CRUD للمورد، إضافة شراء ودفع، ذمم دائنة. `supplier_id` و`purchase_id` اختياري | يجب تسوية الدفعات وفق مرجعها. حركة الشراء المالية في المصدر لا تثبت استلام المنتجات |
| Wallets | إنشاء وتعديل/تفعيل وتسوية ومصروفات وتقارير ومراجعة. `WalletLedgerService` | حدود يومية وشهرية ورسوم وعمولات. منع التعديل الصامت للأرصدة أو إدخال أثر مكرر |
| Wallet cashier | إرسال/استقبال وتسوية المؤجل وعكس الحركة | فصل أثر رصيد المحفظة عن أثر الصندوق وعن عمولة العميل. مرجع عكس وتسوية فريد |
| Damaged stock | بحث منتج وتسجيل وتعديل وإلغاء هالك. `DamagedStockService` | لا يسمح حذف التاريخ أو تجاوز المخزون. إعادة الرصيد في حركة عكسية |
| Maintenance | CRUD، حالة إصلاح وإغلاق وبيانات عميل/جهاز | تحقق من الانتقال، ومن الخصوصية والدفعات عند ربطها بالصيانة |
| Sales reports | عرض المبيعات وفلاتر في `SalesController` | تحديد مصدر واحد للأرقام وفصل المرتجع والدفعات عن إجمالي المبيعات |
| Staff | `StaffController` لإدارة الحسابات وتفعيلها وأدوارها | التحقق من تعطيل الجلسات وعدم حذف آخر مشرف فعّال |
| Roles | `RoleController` وSpatie. صلاحيات الصفحات والعرض والإدارة، مع سياسات العمليات | تحويل قواعد صلاحيات المصدر إلى صلاحيات Worker بعد مراجعة؛ فحص الخادم لكل كتابة مالية |
| Notifications | إشعارات عامة ومستهدفة وحالة قراءة، إنشاء/حذف إداري | الوصول حسب المستلم وخصوصية الرسالة، وقراءة مستقلة لكل مستخدم |
| Backup / restore | تصدير قراءة وتصدير ZIP/XLSX قابل للاستيراد، وصيغة NDJSON أقدم | تفريق التصدير عن نسخة SQL القابلة للاستعادة. حصر النسخ على مسؤول التشغيل واستعادة في D1 معزولة |
| Settings / profile | تعديل ملف وبيانات الدخول وإعدادات النظام | كلمات المرور يعاد إصدارها، وإنهاء التوكنات بعد التغيير. يراجع دور إدارة الإعدادات |
| Android | `StoreApi.kt` و`ApiModels.kt` و`SessionRepository.kt` وتخزين آمن للتوكن | المصادقة جزء مستقل من التوافق. DTOs والأسعار وصيغ النسخ وعمليات الكتابة تحتاج اختبارات تعاقد Kotlin |

تسجل [خريطة REST](API_ENDPOINT_MAP.md) مسارات الإصدار الأصلي وما يقابلها في Cloud Edition. لا تعني مطابقة اسم المسار تطابق عقد الطلب أو الاستجابة.
