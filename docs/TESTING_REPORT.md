# سجل اختبار Cloud Edition

مرجع Laravel `90baabb4b38ae292ea7ef55806145518774991bb`. الاختبارات استخدمت بيانات اصطناعية.

| الفحص | النتيجة |
|---|---|
| Worker TypeScript و`npm test` | نجح الفحص ومرّ 20 اختبارًا من 20 باستخدام Worker/Miniflare وD1 محلية واختبارات قيود SQLite. |
| المصادقة والصلاحيات | نجحت الجلسة وCSRF وOrigin، وصلاحيات السجلات والتقارير والتصدير، وتغيير كلمة المرور، وإبطال الجلسة، وحد المحاولات، وتوكن Kotlin. |
| التزامن | نجحت اختبارات التنافس على آخر قطعة، والسداد المتزامن، والاسترجاع لمرة واحدة، وسحب المحفظة وتسوية الدين المؤجل، والتراجع وإعادة المحاولة بمفتاح واحد. |
| منطق الموديولات | شمل الاختبار التصنيفات والعملاء والمنتج والصورة والإشعارات ودفعات الموردين والأقساط والديون والمحافظ والهالك والصيانة. |
| D1 migrations | طُبقت `0001` و`0002` و`0003` في Wrangler محليًا وعلى قاعدة Cloudflare التجريبية المنفصلة. |
| اختبار ترحيل الكتالوج | طابق Dry Run وإعادة التشغيل تصنيفًا واحدًا ومنتجين وعميلًا و20 وحدة مخزون. مجموع أسعار العينة 5735 وحدة صغرى. طُبقت عينة SQL محليًا. |
| تصدير واستعادة D1 | استعدنا نسخة Wrangler في قاعدة محلية منفصلة. تطابق المخطط وأعداد الصفوف والمفاتيح والمجاميع، بما يشمل 4 حركات مخزون وفاتورة 4235 وحدة صغرى واسترجاعًا واحدًا. |
| Web / Pages | نجح بناء TypeScript وVite وتجميع Pages Functions. حزمة JavaScript الأساسية 103.21 kB gzip وCSS ‏3.77 kB gzip، وجزء الباركود 14.75 kB gzip. |
| المتصفح المدمج | نجح الدخول، وبيع منتج بـ42.35 جنيهًا، وعرض فاتورته واسترجاعها، والتحقق من حركتي المخزون. عرض 390 بكسل كان RTL بلا تجاوز أفقي للصفحة. |
| تجربة HTTPS | نجح تسجيل الدخول عبر Pages وService Binding، وبيع 42.35 جنيهًا واسترجاعه، وإعادة المخزون إلى 20 وحدة. رُفض مسار الموظفين بعد الخروج. اختبارات الصلاحيات حسب الدور نُفذت محليًا. |
| الاعتماديات | فحص اعتماديات الإنتاج في API والواجهة أفاد بصفر ثغرات معروفة في لحظة الفحص. |
| Android | نجح اختبار عقد HTTP للدخول و`me` والإلغاء، ونجحت عمليات البحث والدفع والباقي وإعادة المحاولة لعقد نقطة البيع. لم يبدأ Gradle اختبار Kotlin لأن بيئة التنفيذ تفتقر إلى `JAVA_HOME` و`java` على PATH. |

الحجم المجمع لـWorker في `wrangler deploy --dry-run --minify` هو 125.19 KiB gzip، ووقت بدء Worker الذي أفادت به Cloudflare هو 25 ms. سجّلت Cloudflare 20 استدعاءً ناجحًا في العينة المحدودة، بوسيط CPU قدره 4 ms وأقصى قدره 33 ms. استغرق تسجيل الدخول 33 ms، والبيع 6 ms، والاسترجاع 5 ms. تجاوزت بعض الاستدعاءات حد 10 ms رغم نجاحها. ما زالت المطابقة مع Laravel باستخدام Fixtures مشتركة، وقياس الحصص تحت حمل واقعي، واختبارات الطباعة الفعلية معلقة.
