# حالة HENRA Store Management — Cloud Edition

الفرع `cloudflare-full-migration` مبني على `90baabb4b38ae292ea7ef55806145518774991bb`. [التشغيل والنشر](DEPLOYMENT_GUIDE.md) و[نتائج الاختبار](TESTING_REPORT.md) و[خريطة REST](API_ENDPOINT_MAP.md).

نُشرت تجربة HTTPS على [Cloudflare Pages](https://henra-store-demo-ui.pages.dev) مع [نقطة صحة Worker](https://henra-store-demo-api.heshambackup23.workers.dev/health). قاعدة `henra-store-demo-db` تحتوي على ثلاث ترحيلات وسجلات اختبار اصطناعية. تحققت لوحة الحساب من Workers Free. تم النشر الأول للواجهة بالرفع المباشر، ويتطلب النشر التلقائي من GitHub ضبط بيانات الاعتماد ومتغيرات بيئة النشر.

أداة الترحيل الحالية تغطي الكتالوج والعملاء. نقل الحسابات والتاريخ المالي يتطلب نسخة MySQL معتمدة وقواعد مطابقة للأرصدة. لم تُستخدم بيانات التشغيل في هذه التجربة.

أعلى عينة وقت CPU كانت 33 ms لطلب تسجيل الدخول، مقابل حد مرجعي 10 ms. نجحت العينة وظيفيًا، وتتطلب ملاءمة المصادقة للحمل على الخطة المجانية عملًا إضافيًا قبل الاعتماد التشغيلي.
