# استعادة نسخ هلال القديمة

تقرأ الأداة أرشيف ZIP الإصدار 2 الذي يصدره Laravel ويضم `manifest.json` وملفات `pages/*.xlsx`. تقرأ أيضًا ملف XLSX مباشرًا عندما تكون الأوراق بأسماء جداول Laravel وتضم أعمدة السجل الخام. يمكن تجميع ملفات XLSX المباشرة من اللقطة نفسها باستخدام `--add-workbook`. ملفات تقارير Excel أو CSV القديمة تعرض بيانات مختارة، وتحتاج إلى النسخة الأصلية لاستعادة المفاتيح وبنود الفواتير.

شغّل الأوامر من `cloud/api` بعد `npm ci`. استخدم مجلدًا خاصًا خارج المستودع للأرشيف وملفات SQL وقواعد SQLite. التواريخ داخل قاعدة المصدر التي لا تحمل إزاحة تحتاج إلى المنطقة الزمنية الفعلية عند حفظها. يُستخدم وقت الإصدار المسجل في بيان ZIP عند استعادة الفواتير، أو وقت اللقطة الذي تمرره بـ `--cutoff-at` لملف XLSX. إذا كانت فواتير أو أرصدة المصدر تعتمد على أكثر من ملف، استخدم ملفات من لقطة واحدة.

```powershell
node scripts/restore-laravel-backup.mjs "D:\HilalPrivate\backup.zip" --source-time-zone Africa/Cairo
node scripts/restore-laravel-backup.mjs "D:\HilalPrivate\backup.zip" --source-time-zone Africa/Cairo --output "D:\HilalPrivate\rehearsal.sqlite"
node scripts/restore-laravel-backup.mjs "D:\HilalPrivate\backup.zip" --source-time-zone Africa/Cairo --actor-id 1 --emit-d1-sql "D:\HilalPrivate\rehearsal.generated.sql"
```

الأمر الأول يختبر الاستعادة في ذاكرة SQLite ويطبع تقريرًا بأعداد السجلات، وبصمة الملفات، وإجماليات المطابقة. الخيار الثاني ينشئ ملف SQLite جديدًا للفحص. الخيار الثالث يصدر SQL بعد نجاح المطابقة. طبّق ملف SQL على D1 معزولة ومهيأة بالترحيلات وبحساب مسؤول واحد للترحيل. يستخدم الملف رقم ذلك الحساب في روابط السجل. يوقف الحارس تحميل الملف إذا كانت هناك سجلات عمل موجودة.

تُستعاد التصنيفات والمنتجات والعملاء، والفواتير والأقساط المرتبطة والمستقلة والديون الشخصية ودفعاتها حين تتطابق مبالغها ومراجعها. تُستعاد طلبات الصيانة من جدول Laravel وتُراجع حالتها وتواريخها. جدول الصيانة القديم لا يحتوي على دفتر مدفوعات. تتطلب الفواتير أوراق المنتجات والعملاء والأقساط والمبيعات وبنودها والمدفوعات والديون القديمة حتى لو كانت فارغة. عند تعذر تحديد عميل الفاتورة باسم مطابق وحيد استخدم `--invoice-customer-map` لتمرير ملف JSON خاص يربط رقم الفاتورة بمعرف العميل في المصدر. الفاتورة المدفوعة بالكامل تقبل ربطًا بقيمة `null` عندما لا يوجد عميل محفوظ. أي رصيد سابق مسجل تراكميًا يبقى رصيدًا تراكميًا. تُحفظ تواريخ السداد الموجودة، وتبقى صور المنتجات والصيانة ملفات منفصلة.

يظهر التقرير `blocked_counts` إذا احتوت اللقطة على جداول أعمال لها سجلات تتطلب مطابقة إضافية، مثل المحافظ والموردين والهالك أو المبيعات القديمة. تتطلب الفاتورة المستردة مستندات تثبت حركة الاسترداد والمخزون. تُستبعد جداول المصادقة وحسابات المستخدمين من إعادة التهيئة وتظهر أعدادها في التقرير. يلزم إنشاء حسابات جديدة وتعيين الأدوار عند التهيئة.
