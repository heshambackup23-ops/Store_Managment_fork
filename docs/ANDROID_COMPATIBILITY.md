# توافق Android

يستهدف Kotlin الإصدار `v1` من خلال Retrofit، ويخزّن التوكن في `SecureTokenStore`. يعيد Worker استخدام المسارات `/api/v1/auth/token` و`/api/v1/me` مع `username` و`device_name` لبنية دخول Kotlin. يطابق توكن الدخول الحقول `access_token` و`token_type` و`expires_at` و`user`، ويمكن إلغاؤه عبر `DELETE /api/v1/auth/token`.

يتصل إصدار `staging` افتراضيًا بعنوان Pages التجريبي عبر HTTPS. يرسل العميل `X-Store-Client: android` لاختيار تمثيل Retrofit عند استخدام توكن Bearer. للتقييم على الجهاز، شغّل تهيئة مستخدم باسم دخول ثم اطلب إصدار التوكن وفحص `me` وإلغاءه.

تغطي مواءمة HTTP الكتالوج والعملاء والكاشير والفواتير والأقساط والديون والموردين والصيانة والمحافظ والهالك والإشعارات. اختبارات Worker تستخدم حمولات Retrofit للكتابة وتفحص الصلاحيات والآثار على المخزون والأرصدة. إنشاء قسط أو تحويل محفظة مؤجل باسم العميل يتطلب عميلًا موجودًا يطابق الاسم دون التباس. تعديل الفاتورة يتم بالاسترجاع وإعادة الإصدار، وسداد الدين يسجّل من شاشة الدفع. تغيير صنف قيد الهالك يتطلب عكسه ثم تسجيل قيد جديد. راجع [خريطة المسارات](API_ENDPOINT_MAP.md).

يولّد إصدار هلال التجريبي PDF للفواتير محليًا في Android بدعم تشكيل النص العربي. في [تشغيل المحاكي Android 15](https://github.com/heshambackup23-ops/Store_Managment_fork/actions/runs/43375944205)، فتح APK التجريبي شاشة الدخول ووصل إلى Cloudflare. أثبتت نسخة موصولة بـWorker وD1 معزولتين تسجيل الدخول وعرض الكتالوج وإضافة منتج وتسجيل الخروج، وفتح PDF عربي متعدد الصفحات. لم يُجر الاختبار على جهاز فعلي. استعادة ZIP/XLSX القديمة تتم [بأداة الإدارة المعزولة](LEGACY_BACKUP_RESTORE.md).
