# مراجعة الأمان

- يستخدم Worker توكنات عشوائية قصيرة العمر، ويخزن تجزئتها، ويعيد تقييم حالة المستخدم ودوره في قاعدة البيانات عند كل طلب. تستخدم الواجهة Cookie من نوع `HttpOnly` و`SameSite`، وتكون `Secure` عبر HTTPS. يفرض التعديل بجلسة المتصفح ترويسة CSRF ويفحص Origin. يستخدم Android توكن Bearer.
- تُحمى كلمات المرور باشتقاق PBKDF2 وملح مستقل وpepper في Worker Secret. حد تسجيل الدخول لكل حساب وعنوان يقلل المحاولات. استغرق طلب الدخول السحابي المقاس بكلمة مرور 33 ms من CPU، وهو فوق الحد المرجعي للخطة المجانية. كلمات مرور Laravel القديمة وتوكنات Sanctum تستبدل عند تهيئة الحسابات.
- يدعم وضع مفاتيح الدخول اعتمادًا سريًا عشوائيًا بطول 256 بت يولّده الخادم أو أداة التهيئة، ويخزن D1 قيمة HMAC-SHA-256 مع ملح مستقل وpepper. يدخل المستخدم المفتاح في حقل كلمة المرور نفسه. يتطلب تدوير المفتاح ذاتيًا إعادة إثبات الاعتماد الحالي ويلغي الجلسات الأخرى، ويلغي إعادة الإصدار الإداري جميع جلسات الحساب. في اختبار محلي عبر Miniflare وD1، بلغ وسيط زمن الطلب الكامل 8.63 ms للمفتاح و68.07 ms لكلمة المرور، عبر ثمانية طلبات ناجحة لكل وضع بعد الإحماء. يحتاج حد CPU إلى قياس طلب ناجح في Cloudflare.
- يتطلب دفتر العميل `customers.view` وتخضع بياناته المالية لصلاحيات كل موديول. يستبعد رصيد الفواتير الرصيد المحوّل إلى قسط فعّال عند ظهور الفواتير والأقساط معًا، حتى لا يُحسب الدين مرتين.
- يرفض الخادم الطلبات غير الصالحة ويفحص الصلاحية قبل إدارة الكتالوج أو إجراء المعاملة. تُسجّل التغييرات الحساسة في D1 مع هوية الفاعل ومرجع العملية، وتُمنع تعديلات دفاتر الحركة التاريخية.
- تتطلب صور المنتجات صلاحيات الكتالوج. تخزين التجربة محدود بالحجم والعدد والصيغ. تنزيل CSV يحتاج `backup.export`، ويعالج حقول النص التي قد تتحول إلى صيغ في تطبيقات الجداول.
- راجعنا مسارات الأسرار والنسخ في لقطة Laravel وبحثنا عن مؤشرات نصية شائعة لمفاتيح خاصة وتوكنات. يوجد `.env.example` وصور منتجات موروثة في `public/uploads`. يقتصر هذا الفحص على لقطة الشفرة والمسارات المقروءة. تحتاج الصور الموروثة والتاريخ الكامل إلى مراجعة مستقلة قبل إعادة استخدامها خارج المشروع.
- ملفات الأسرار وبيانات Wrangler والنسخ وملفات SQL والمفاتيح المولّدة مستبعدة من Git. بيانات العرض المستخدمة في الاختبارات اصطناعية.

نجح الدخول والجلسة والرفض بعد الخروج عبر HTTPS. تبقى مراجعة أدوار الاختبار في البيئة السحابية، ومعالجة حمل CPU للمصادقة، واختبار حدود الحصص، ومراجعة توافق Android كاملة ضمن تحقق ما قبل التشغيل.
